# Portfolio collaborations strip

The approved preview shows six marks in alphabetical order. The existing portfolio images stay unfiltered. The greyscale styling applies only to the six locally hosted originals, leaving brand shapes and aspect ratios intact.

Original artwork sources:

- Amazon: [US Press Center](https://press.aboutamazon.com/logos), standard dark wordmark with orange smile.
- Australia Post: [Australia Post](https://auspost.com.au/), desktop header mark.
- Blue Yonder: [Blue Yonder](https://blueyonder.com/), blue brand lockup from the site header.
- ConvergentIS: [ConvergentIS](https://www.convergentis.com/), full-colour header wordmark.
- Farfetch: [Farfetch press releases](https://www.farfetch.com/stories/press-releases), header wordmark.
- Zeelo: [Zeelo](https://zeelo.co/), dark header lockup.

This is a local review candidate. Sourcing a mark from its official website does not establish permission to publish it or recolour it. Check the applicable rules and use official monochrome variants where available before public release; a plain-text brand name is a fallback if the permitted artwork cannot be used. Start with [Amazon press assets guidance](https://press.aboutamazon.com/images-and-videos) and [Australia Post logo guidance](https://auspost.com.au/about-us/about-our-site/using-our-logo).
